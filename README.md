# Smart Ops Mobile

React Native mobile application for field service management — part of the Smart Ops ecosystem.

## Tech Stack

**React Native** · **TypeScript** · **Expo** · **REST API** · **Push Notifications**

## Features

- **Field Service** — Job assignments, real-time status updates, GPS check-in
- **Client Portal** — View service history, schedule appointments, chat
- **Inventory** — On-the-go stock lookup and adjustments
- **Notifications** — Push alerts for new jobs, schedule changes, and updates
- **Offline Support** — Queue operations when offline, sync when connected

## Requirements

- Node.js 18+
- Expo CLI
- Android SDK / Xcode

```bash
yarn install
npx expo start
```
